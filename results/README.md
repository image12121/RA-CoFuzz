# Public results

`aggregate/summary.json` is the canonical machine-readable public result. It contains protocol metadata, 144 content-free cell summaries, condition aggregates, means, and sample standard deviations.

`tables/` contains manuscript-ready Markdown projections of the same data. The public checks validate cell counts, label totals, response totals, seed coverage, question coverage, tables, and figures against this frozen aggregate. The historical private per-response tree is not included in the retained release materials, so the published numbers cannot currently be re-derived from their original generation/evaluation markers.

Raw model conversations are not part of this public repository. See `docs/DATA_AND_RELEASE_POLICY.md`.
